# Schematic test fixtures (ADR-058)

Reproducible, license-clean schematic fixtures for the region-specific schematic
paste feature ([ADR-058](../../docs/adr/ADR-058-region-specific-schematic-paste.md)).
Every file here is authored in-repo (no third-party build is vendored), so it
ships under the repository's own license and can be regenerated byte-for-byte.

## `skyblock_island.schem`

A small skyblock starter island in the **Sponge Schematic v3** format - the
format modern WorldEdit / FastAsyncWorldEdit write by default (v3 is also what
FAWE produces today; v2 remains readable by older tooling if you ever need it).

- Generate: `python scripts/schematics/generate_skyblock_island.py`
- Verify:   `python scripts/schematics/verify_skyblock_island.py`

### Contents (verified by the round-trip script)

- Dimensions `8 x 10 x 7` (W x H x L), 560 cells, 6-entry palette.
- L-shaped footprint of 27 columns (a 6x3 arm plus a 3x3 arm).
- 3 dirt layers under the footprint => **81 dirt blocks**; **27 grass_block** on top.
- One **oak tree** (4 oak logs + 54 oak leaves) on the far +X **outer edge** of the dirt.
- One **chest** in the middle of the 3x3 arm, on the opposite side from the tree,
  sitting on the grass, containing **1 ice + 1 lava bucket + 10 obsidian**.
- Every remaining cell in the bounding box is `minecraft:air` (393 cells).

### Intended paste behavior

The empty cells are stored as air **on purpose**, but the paste path uses
`pasteAir = false` (`PasteOptions`), so air never overwrites surrounding terrain.
The `BOTTOM_CENTER` `PasteAnchor` puts the grass platform directly under the
arriving player's feet; `rtp-core` is expected to choose the column from the
middle of the footprint outward, falling back through `vert` checks until a
valid column is found before any overwrite. See ADR-058 for the full contract.

### Reference look

The shape and contents target the look of common community skyblock starter
islands (L-shaped dirt pad, single tree at one corner, a chest of starter items
at the other). Coordinates/blocks are authored here, not copied from any third
party.
