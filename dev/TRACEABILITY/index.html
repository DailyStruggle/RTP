    RTP Requirements Traceability Matrix¶

    This document connects each requirement to the design decision that motivated it and the source code that implements it. Where automated tests exist, they are linked as well.

    How to read this table - Req ID — unique identifier from the relevant REQUIREMENTS.md file. - Design Ref — section in DESIGN.md or ARCHITECTURE.md that describes the decision. - Implementing Class(es) — primary source file(s) that satisfy the requirement. - Test(s) — automated test(s) that verify the requirement, if any.
