    CHECKLIST: MultiConfig submenu (regions, worlds, future kinds)¶

    Effective Issue: Append region and world settings to the runtime book menu, with a generic submenu pattern keyed by MultiConfigParser kind. Region "default" and any server-loaded world cannot be removed. Add via anvil-input prompt; remove via toggled mode. Locked rows shown gray with hover reason.

    Mode: [CODE] when implementing. Author session (this one): docs-only, no code changes.

    Companion proposal: docs/dev/scratch/PROPOSAL-multiconfig-menu.md (full design + mermaid chart).

    Awaiting user approval: None. User approved the design in the proposal-review exchange on 2026-05-22.

    Resume protocol: On session resume, re-verify the latest [x] step (file exists / test still green / commit still HEAD), then continue from the first [ ] step.
