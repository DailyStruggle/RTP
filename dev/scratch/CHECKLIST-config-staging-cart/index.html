    CHECKLIST: Config Menu Staging Cart¶

    Effective Issue: /rtp config menu submenus should stage parameter edits in a per-session cart (showing "Changeable" + "Pending" lists) and Apply them in one batched /rtp config <file> k1=v1 k2=v2 ... command instead of running each edit immediately on anvil-confirm. Cart is scoped to a single file and silently dropped on return to the file-selector page. Mode: [CODE]. D-005 proposal: approved.
