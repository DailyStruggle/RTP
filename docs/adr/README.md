# Repository Architecture Decision Records

This directory contains repository-level Architecture Decision Records (ADRs) governing development workflow, repository and module file structure, quality and fuzzing gates, licensing, and Java/Minecraft baseline support.

Module-, library-, platform-, and plugin-specific ADRs live inside their owning subproject's `<subproject>/docs/adr/` directory (cataloged under [Subproject ADRs](#subproject-adrs) below).
